Tracks zero-result site searches and exposes content demand candidates through MCP abilities.

== Description ==

MCP Abilities - Content Demand records frontend site searches that return no results, aggregates them, and exposes the resulting content-demand candidates to MCP clients.

It does not auto-publish content and does not add a WordPress admin report. Candidates are demand evidence for a content workflow: verify facts, write high-quality Gutenberg content, and review before publishing.
