# Dependencies

MCP Abilities - Content Demand depends on the established WordPress ability stack. Each link goes to the component that performs the named job.

- [WordPress 6.9 or newer](https://wordpress.org/download/) provides the Abilities API used to register typed operations.
- [PHP 8.0 or newer](https://www.php.net/supported-versions.php) provides the required server runtime.
- [WordPress MCP Adapter](https://developer.wordpress.org/news/2026/02/from-abilities-to-ai-agents-introducing-the-wordpress-mcp-adapter/) exposes registered WordPress abilities through Model Context Protocol.
- [MCP Expose Abilities](https://devenia.com/plugins/mcp-expose-abilities/) supplies the controlled public ability surface used by this add-on.

Install this add-on only after those dependencies are active.
