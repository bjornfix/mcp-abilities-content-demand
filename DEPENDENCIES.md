# Dependencies

MCP Abilities - Content Demand depends on the established WordPress ability stack. Each link goes to the component that performs the named job.

- [WordPress Abilities API](https://developer.wordpress.org/apis/abilities-api/) requires WordPress 6.9 or newer and registers the typed operations.
- [PHP 8.0 or newer](https://www.php.net/releases/8.0/en.php) provides the required server runtime.
- [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter/) exposes registered WordPress abilities through Model Context Protocol.
- [MCP Expose Abilities](https://devenia.com/plugins/mcp-expose-abilities/) supplies the controlled public ability surface used by this add-on.

Install this add-on only after those dependencies are active.
